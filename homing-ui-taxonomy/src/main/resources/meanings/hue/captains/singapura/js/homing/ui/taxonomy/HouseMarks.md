# The house's marks and tracks

## Icon

A glyph from the house's vocabulary, standing for one idea wherever it is shown.

## Detent

Marks a value the user's movement may settle on.

## Tick

Marks one step of a scale.

## Separator

Marks where one group or step ends and the next begins.

## Lamp

Says by a light how something is: alive, dormant, broken.

## DropMark

Shows where a dragged thing would land.

## Indicator

A small sign of a state: which one is current, which one has the keys.

## Groove

The line a value is set along: the whole of its range.

## Fill

The part of the range the value has reached.
