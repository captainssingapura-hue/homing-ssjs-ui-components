# The house's regions

## Section

A stretch of a container's room given one job: its head, its body, its foot.

## WidgetSlot

A stretch of a view where a widget is held, loaded when it is needed.

## Quote

Holds words quoted from elsewhere, set off so they are read as another's.

## CodeBlock

Holds lines of code, or of a log, exactly as written, each line kept.

## Table

Sets facts out in rows and columns, so they can be read across and compared down.
