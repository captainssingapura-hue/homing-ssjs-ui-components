# The house's text

## Label

Words that name a control or a field, so the user knows what using it will touch.

## Heading

Words that say what a container holds, read first.

## Kicker

A few words above a heading that say where it belongs.

## Caption

Quiet words beside something, adding to it without competing with it.

## Lede

The first words of a body, saying what follows in brief.

## Readout

A value read out exactly, as it stands now.

## Badge

A short word that sorts or flags what it is beside.

## Pill

A count, kept short, of what cannot all be seen.

## Wordmark

A name set as the mark of whom it belongs to.
