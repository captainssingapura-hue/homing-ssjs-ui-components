# The house's controls

## PlainButton

Does one ordinary thing, with nothing to warn of and nothing to lead with. The button to use when
none of the others is meant.

## PrimaryButton

Does the one thing a view leads with - the action most users came for. One to a view at most.

## SecondaryButton

Does a thing beside the primary one: offered, not urged.

## DangerButton

Does a thing that destroys, or cannot be undone. Used only where that is true, so the user learns
to stop at it.

## WarningButton

Does a thing that deserves a second thought, though it can be undone.

## SuccessButton

Does a thing that completes what went well: accepts, finishes, confirms a good outcome.

## ToggleButton

Turns one thing on or off, and shows which it is, each time it is pressed.

## IconButton

Does one thing named by a glyph alone, where the glyph is known well enough to need no words.

## CloseButton

Closes what it is on.

## Knob

What the user takes hold of to move a value along a track.

## Grip

What the user takes hold of to move the thing it is on.

## Divider

What the user takes hold of to move the line between two regions, giving one more room.

## Link

Takes the user somewhere else, and says where.

## Crumb

Takes the user back to one place on the way they came.

## Tab

Brings forward one of the things a pane holds, and stands for it among the others.

## Range

Sets a number along a scale, natively, with no more than the scale itself.

## Select

Sets one value from a list that opens when asked and closes once picked.

## Switch

Sets a setting on or off, in one movement, and shows which it is.

## PaneThumb

Picks one pane by a small picture of where it is.

## Brand

Says whose site this is, and takes the user home.

## PreferencesButton

Opens the site's preferences, where the user sets how the site behaves for them.

## Slider

Sets a value along a scale the user can see: its name, its range, where it rests, its steps, and
the value read out as it moves.
