# The house's words

## Acting

What a control does to the thing it is on, said by the mark on the control: close it, one more of it.

## Telling

How the thing the mark is on is - chosen, done - or what the hand may do with it.

## Leading

That there is more behind the thing the mark is on: more beneath it, or what it is set by.

## Measuring

An axis the thing the mark is on is measured along: how big it is, how much of it there is.

## Add

One more: a new tab, a new row, a new note.

## Remove

One fewer: this one taken away.

## Close

Close it: a tab, a pane, a dialog - each closed by the same word, drawn once in each style.

## Reset

Back to the start: what was changed set as it was.

## Rotate

Turn it a step.

## Flip

Mirror it.

## Pin

Keep it where it is: it stays when others move or go.

## Check

This one is chosen, on, done.

## Grip

Take hold of it: the mark on a knob, a handle, a thing the hand moves.

## Disclose

There is more beneath: a row that opens its children, a node that expands.

## Settings

The settings behind it: what it is set by, to look at and change.

## Size

Bigger or smaller: the size axis.

## Aspect

Wider or taller: the aspect axis.

## Extent

More or less of what it means: the extent axis.

## Level

How much of it: a level, a volume, a gain.
