# Saying - what a part tells about its owner

## Saying

A part that tells the user something about its owner: what it is, what more there is to know,
how to use it, how it is now, where it stands. It informs, and changes nothing.

## Naming

Says what the owner is, so the user can tell it from the others.

## Title

Names a container - a card, a panel, a pane, a group, a setting - so the user knows what it holds
before looking inside.

## Subtitle

Names one section of its owner, under the owner's title.

## Name

Names a control or an item, so the user knows which one they are about to use.

## Category

Says what sort of thing the owner is, above its title, so the user knows where they are.

## Symbol

Stands for the owner by a glyph, so the user knows it at a glance, before reading anything.

## Describing

Says more about the owner than its name does.

## Summary

Says briefly what the owner is about, so the user can decide whether to go further.

## Note

Remarks on the owner as it is now: where a value came from, that a pane is empty, what a choice
will mean.

## Tag

Marks the owner with a short word that sorts it among others like it.

## Guiding

Helps the user use the owner.

## Hint

Tells the user a faster way to the same thing, such as a shortcut.

## Prompt

Asks the user what to do next, when the owner waits on them.

## Reporting

Says how the owner is now, as it changes.

## Value

States the owner's value in words or figures, exactly as it stands.

## Level

Shows how far along its range the owner's value is, at a glance rather than exactly.

## Count

Says how many the owner holds, where they cannot all be seen.

## Status

Says how the owner is doing: loading, ready, failed.

## Signalling

Shows a state or a place by a mark rather than by words.

## Keys

Shows that the keyboard is with the owner: what the user types goes there.

## Landing

Shows where a dragged thing would land if it were let go now.

## Disclose

Shows that a choice leads to further choices, rather than doing something at once.

## Scaling

Marks out the scale the owner's value lies on.

## Span

Shows the whole range the owner's value can take.

## Rest

Marks where the owner's value rests when nobody has set it.

## Notch

Marks one step the owner's value can stop at.

## Figure

Numbers a step of the owner's scale, so the user can read the scale itself.
