# The house's branches

## Control

Something the user operates to make a thing happen: press, pick, move, go. A control acts on
the user's word and only on it.

## Button

A control that does one thing, once, when the user presses it. What it does is said on it, and
how much it matters is its kind: the house's buttons differ in consequence, not in what they are
for.

## Handle

A control the user takes hold of and moves, so that something moves with it.

## Item

One of many alike, offered or listed by what holds it; it means something only among the others.

## Container

Holds other components together as one thing to the user, and gives each its place. What it
holds is the point; the container serves it.

## Card

Stands for one thing among others like it, whole and apart from them, so the user can compare
them and pick one.

## Pane

Holds content the user works in, with a frame of its own that it keeps however the content
changes.

## Menu

Offers the user a set of choices for as long as they need them, then gets out of the way.

## Layer

Holds what is shown over the page, apart from its flow, for as long as it is needed.

## Split

Shares a room between several things, each given its share, and lets the user change the shares.

## Bar

A thin band along an edge that carries controls or a way through, never the content itself.

## Field

Lets the user set one setting, and says what it is and how it stands.

## View

Shows something whole, for the user to look at or look through, rather than to edit.

## Region

A stretch of a container's room with a job of its own, but no frame of its own.

## Text

Words the user reads; they inform and do nothing.

## Track

A line a value lies along, or fills, so its place can be seen.

## Mark

A small sign the user reads at a glance, in place of words.
