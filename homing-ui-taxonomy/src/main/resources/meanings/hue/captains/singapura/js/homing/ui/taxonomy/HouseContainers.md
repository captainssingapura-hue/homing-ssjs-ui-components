# The house's containers

## PlainCard

Stands for one thing, and holds whatever its user puts there. The card to start from when no
case of it fits.

## SummaryCard

Sums one thing up - its title, how it is sorted, what it is about - and leads to it, so the user
can choose among several at a glance.

## SliderGroup

Gathers sliders that set related values, under one heading, so they are set together.

## Panel

Holds one concern of a view, named, filling the room it is given.

## Dialog

Puts one matter to the user above the page, and holds the page back until it is settled.

## PaneThumbs

Shows where the panes are, small, so the user can pick one by its place.

## AddTab

Opens a new tab: the user says what kind, where it goes, and how it arrives.

## TabOpener

Offers what an empty pane can open, so it is never a dead end.

## TabPicker

Asks which kind of tab to open in a pane, and lets the user decline.

## MpaChrome

Frames every page of a site the same way: whose site it is, where the user stands in it, and
their preferences, around the page's own room.

## FloatingPane

Holds content in a window of its own over the page, which the user can move and close.

## MultiTabPane

Holds several tabs in one place, one in front at a time, and lets the user move between them,
add to them and rearrange them.

## SingleTabPane

Holds one tab, named, as a pane of many would, so it can join one later.

## TabPane

One open tab, whole: what it shows and the chip that stands for it, travelling together wherever
the tab goes.

## ContextMenu

Offers the choices that apply where the user asked, there, and closes once one is made.

## FloatLayer

Keeps the panes floating over the page, and which is in front.

## Scrim

Holds the page back while something above it asks for the user's attention.

## ContextMenuSteward

Keeps the page's context menus: one open at a time, the right one for where the user asked.

## SplitPane

Shares a room between regions, split and split again, the lines between them movable.

## SplitGrid

Shares a room between regions in rows and columns, the lines between them movable.

## SplitGridMirror

Shows the shape a split grid has, small, so it can be read and pointed into.

## DockGrid

Shares a workspace between tabbed panes, so the user arranges their work as they like.

## EdgeStrip

Keeps controls out of the way at an edge until the pointer reaches for them.

## TabStrip

Lines up a pane's tabs, says how many are out of sight, and lets the user add one, close the pane,
and drop a tab into place.

## PanZoomBar

Reads out how near a picture is, and brings it nearer, takes it further, or fits it whole.

## ActionBar

Lines up the actions that end a matter, the one to lead with apart.

## Trail

Shows the way from the site's home to where the user is, each step a way back.

## PreferenceField

Presents one setting: where it belongs, what it is, what it does, how it stands, and the way back
to its default.

## ChoiceWidget

Sets a setting to one of a few values, each said with what it means.

## ThemeWidget

Sets the theme: a style, and a palette to wear it in.

## ScaleWidget

Sets a setting to a number along a scale, read out.

## ToggleWidget

Sets a setting on or off.

## ListMasterWidget

Lists the site's settings by where they belong, so the user picks one to see beside the list.

## OverviewWidget

Presents a group of settings at once: what the group is, each setting with its value, and the way
back to the defaults for all of them.

## SvgPanZoom

Shows a picture the user can move around in and bring nearer or take further.

## PreferencesView

Presents the site's preferences: the settings listed by where they belong, and the one picked,
beside the list.

## FocusMonitor

Shows where the keyboard's focus is on the page, as the tree of what holds it.

## StewardMonitor

Shows at a glance where the keys are and whether the page's handling of them is sound.
