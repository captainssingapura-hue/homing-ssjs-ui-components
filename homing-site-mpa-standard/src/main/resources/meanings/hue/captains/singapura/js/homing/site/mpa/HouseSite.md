# The house's standard site

## Brand

Says whose site this is, and takes the user home.

## PreferencesButton

Opens the site's preferences, where the user sets how the site behaves for them.

## MpaChrome

Frames every page of a site the same way: whose site it is, where the user stands in it, and
their preferences, around the page's own room.

## ThemeWidget

Sets the theme: a style, and a palette to wear it in.
